During my internship, I researched and published three technical summary posts covering recent AWS services and capabilities:

### [Blog 1 - Amazon ECS Gateway: Managed Ingress Networking for Containers](3.1-Blog1/)
Introduces **Amazon ECS Gateway**, an account-level resource that automates provisioning and lifecycle management for container ingress infrastructure (ALB, ACM certificates, DNS hostnames, Security Groups), supporting ALB sharing across up to 25 services while separating responsibilities between platform and application teams.

### [Blog 2 - AWS Lambda Web Functions: Run Serverless HTTP Web Apps Directly](3.2-Blog2/)
Summarizes **AWS Lambda Web Functions**, enabling standard HTTP web apps and frameworks (Express, Hono, Fastify, Next.js, etc.) to run natively on AWS Lambda without adapter layers, with concurrent request handling, native HTTP streaming, and Active Compute billing.

### [Blog 3 - AWS Account Access Manager: Centralized Workforce Access with IAM Role Flexibility](3.3-Blog3/)
Explores **AWS Account Access Manager (AAM)**, bridging centralized workforce access administration in AWS IAM Identity Center with account-level IAM role customization while preserving individual user audit attribution in CloudTrail via *trusted identity propagation*.
